# Green River GBA Ocean Microjam!

A Game Boy Advance Microgame collection! Created by Green River College Software Development Cohort 24 students, led by Auberon López.

Instructions are at [instructions.md](./instructions.md). WARNING: waves that have not yet been assigned on Canvas are subject to change. You can still get an early start on them if you like!
